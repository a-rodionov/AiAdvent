# AiAdvent. Задание №8. Работа с токенами

Добавьте в код агента подсчёт токенов:
- для текущего запроса;
- для всей истории диалога;
- для ответа модели.

Сравните:

- короткий диалог;
- длинный диалог;
- диалог, который превышает лимит модели.

Покажите:

- как растёт стоимость/токены по мере диалога;
- что ломается при переполнении.

Результат:

Код, который считает токены и показывает, как они влияют на поведение агента.

Формат:
Видео + Код

## Решение

[Ссылка на видео](https://disk.yandex.ru/i/XYhpkFwodVipUw)

В демонстрационном примере установлен лимит на 500 токенов.
1. В первой сессии каждый ответ модели укладывается в лимит и получаю причину завершения генерации ответа - StopReason.STOP. The model reached a natural stopping point.
2. Во второй сессии в первом запросе к модели содержится требование на генерацию ответа, превышающего лимит (10'000 слов). Поэтому каждый последующий ответ модели стремиться его удовлетворить, но упирается в лимит и прекращается. Причина завершения генерации ответа - StopReason.LENGTH. We exceeded the requested max_tokens or the model's maximum. Последующие запросы на продолжение генерации корректно работают, т.к. в запросах содержится весь предыдущий контекст.
3. Каждый последующий запрос пользователя в сессии содержит всю предыдущую историю сообщений. Таким образом, токены очередного запроса пользователя (input/prompt) аккумулируют все предыдущие токены запросов пользователя и ответов модели. Токены в ответе модели этому не подвержены. В результате в сессии стоимость input/prompt токенов достаточно быстро растет. Ниже приведена статистика использования токенов и их стоимости для второй сессии.
