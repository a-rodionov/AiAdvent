# AiAdvent. Задание №9. Управление контекстом: сжатие истории.

Реализуйте механизм управления контекстом:

- храните последние N сообщений “как есть”;
- остальное заменяйте summary (например каждые 10 сообщений);
- храните summary отдельно и подставляйте его в запрос вместо полной истории.

Сравните:

- качество ответов без сжатия;
- качество ответов со сжатием;
- расход токенов до/после.

Результат:

Агент, который работает с компрессией истории и экономит токены

Формат:

Видео + Код

## Решение

[Ссылка на видео](https://disk.yandex.ru/i/NC0A_Vp6_fk1Dg)

В демонстрационном примере сжатие выполняется после 8 сообщений.

1. Само сжатие требует большого расхода токенов, т.к. запрос включает в себя всю предыдущую несжатую историю + системный промпт и промпт для сжатия.
2. После сжатия история сообщений уменьшается и расход токенов уменьшается.
3. Первое сжатие еще сохраняет некоторые детали из предыдущей истории. Повторное сжатие теряет детали диалогов до предыдущих сжатий. Восстановление контекста путем добавления деталей сжатой истории может частично компенсировать потери.
