  2. Race Conditions in Session Registry

  Files: app/infrastructure/app_factory.py:55,
  app/adapters/controllers/session_routes.py:112,
  app/adapters/controllers/ws_handler.py:136

  The shared sessions dict has no synchronization:
  # app_factory.py:55
  app.state.sessions = {}  # No asyncio.Lock

  # session_routes.py:112 — not atomic
  sc = sessions.pop(session_id, None)
  if sc is not None and sc.ws is not None:  # ws state can change between check 
  and use
      await sc.ws.close(...)

  # ws_handler.py:136 — overwrites task without cancelling previous
  sc.stream_task = asyncio.create_task(...)

  Fix: Wrap sessions in a SessionRegistry class with an asyncio.Lock.

  ★ Insight ─────────────────────────────────────
  The three late imports (from x import y inside a function body) in
  session_file_adapter.py and pricing.py are a classic "smell" that exposes a
  hidden circular dependency. In hexagonal architecture, the fix is usually
  dependency inversion: pass the dependency at construction time (as a
  constructor parameter) rather than importing it at call time. This makes the
  coupling explicit and eliminates the circular import entirely.
